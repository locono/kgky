# 考公考研 kgky.cn

考公考研资料导航站，把备考所需的课程目录、笔记网盘群和更新动态集中在一个页面上，方便快速找到入口。

## 网站内容

- **考公课程目录** —— 公务员、国考省考、教师、事业、文职、三支、社工、英语、财会、司法
- **考研课程目录** —— 英语、数学、政治、管理类联考、专业课、笔试、冲刺、押题、复试
- **笔记网盘群** —— 海量备考笔记的网盘群入口
- **课程更新日志** —— 课程更新动态实时记录

## 主要功能

- 顶部导航栏：站点 logo 与名称、文字导航、当天日期自动显示
- 课程卡片：点击直接跳转到对应的腾讯文档目录
- 页尾公众号：花生考公、考研网盘两个公众号二维码，微信扫码即可关注
- 联系 QQ：点击号码一键复制，并提示「QQ已复制」
- 返回顶部悬浮按钮
- 自适应手机、平板和电脑，不同设备自动缩放

## 技术说明

- 纯静态单文件网站，仅一个 `index.html`，无任何外部依赖
- 公众号二维码已内嵌进 HTML，无需额外图片文件
- 路径 `assets/` 内保留了二维码原图，便于日后替换

## 部署

直接把 `index.html` 上传或连接仓库到 Cloudflare Pages 即可上线，无需构建步骤。
